# Contributing

Thank you for helping improve Layar Katalog.

## Issues and pull requests

- Describe the WordPress/PHP versions and exact steps to reproduce a bug.
- For responsive issues, include viewport size, browser/device, and a screenshot when possible.
- Keep changes compatible with the documented WordPress/PHP requirements.
- Do not submit copyrighted video, images, production database exports, personal data, VAPID private keys, subscription endpoints, passwords, or access tokens.
- Update relevant documentation when behavior or requirements change.
- Run PHP lint and JavaScript syntax checks for touched files. Test WordPress changes on a staging install before release.
